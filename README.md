# Advoc8 design challenge

Interactive prototype of the Advoc8 web app with four side-by-side options.

## Run it

```bash
cd advoc8-replica && python3 -m http.server 8642
```

Then open http://localhost:8642/index.html (or double-click `advoc8-replica/Open Advoc8 Replica.command`).

## The options

Use the Prototype controls panel (bottom right) or press the number keys:

1. **Original**: the app as it is today.
2. **Light touch**: same layout, new search and UX fixes.
3. **Side nav**: one navigation panel.
4. **Rail and panel**: an icon rail with a panel per section.

Press R for the sign-in and onboarding flow. Each page's panel lists the changes made to it.
